## 📌 ¿Qué es GOINTIC Office Toolkit?

GOINTIC Office Toolkit es una herramienta desarrollada en PowerShell para ayudar a técnicos de soporte, administradores de sistemas y profesionales IT a diagnosticar, reparar y eliminar instalaciones dañadas de Microsoft Office.

El proyecto nace tras resolver casos reales donde las herramientas oficiales de Microsoft no conseguían reparar correctamente instalaciones corruptas de Office.

---

## ✨ Funciones principales

- 🔍 Diagnóstico de instalaciones de Microsoft Office
- 🩺 Comprobación del estado de Click-to-Run
- 🛠 Reparación de Office
- 🗑 Desinstalación avanzada
- ⚙ Eliminación de servicios y tareas programadas
- 💾 Copia de seguridad del Registro
- 📄 Informes HTML
- 🧹 Limpieza de restos de Office
- 🔧 Integración con DISM y SFC
- 📦 Compatibilidad con Office Deployment Tool

## 🚀 Instalación

Descarga el script desde este repositorio y ejecútalo como Administrador.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\GOINTIC-Office-Toolkit.ps1
```
